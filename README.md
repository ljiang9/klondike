# klondike

终端 Klondike（经典接龙）纸牌游戏。纯 Python 标准库，零依赖。

## 玩法

```
$ python -m klondike
Klondike 接龙 | 输入 h 看帮助，q 退出
stock:24  waste:--
f1:-- f2:-- f3:-- f4:--
----------------------------------------
##   ##   ##   ##   ##   ##   ♠K
 t1   t2   t3   t4   t5   t6   t7
> _
```

- **tableau（工作区）**：7 列，降序红黑交替堆叠；空列只能放 K。
- **foundation（目标区）**：4 个堆，按花色从 A 升序到 K。
- **stock / waste**：`w` 从牌堆翻一张到废牌堆（draw-1 模式）；牌堆翻空后自动把废牌堆回收重洗。
- 胜利条件：4 个 foundation 各集齐 13 张牌。

## 命令

| 命令    | 说明                          |
|---------|-------------------------------|
| `w`     | 从牌堆翻一张                  |
| `w f1`  | 废牌堆顶 → 目标区 1           |
| `3 f2`  | 第 3 列顶牌 → 目标区 2        |
| `3 5`   | 第 3 列顶牌 → 第 5 列         |
| `3 2 5` | 第 3 列顶部 2 张 → 第 5 列    |
| `w 3`   | 废牌堆顶 → 第 3 列            |
| `u`     | 悔棋一步                      |
| `q`     | 退出                          |

## 参数

- `--seed N`：固定随机种子（可复现牌局）
- `--auto N`：自动 bot 走 N 步后退出（弱策略，仅用于验证）

## 设计取舍

- **draw-1**：每次只翻一张，比 draw-3 简单，适合终端演示。
- **自动 bot 是弱策略**：优先送 foundation、其次 tableau 移动、最后翻牌；不做任何前瞻，胜率很低，仅用于"不出非法移动"的回归验证。
- **列内多张移动**：`3 2 5` 支持一次性搬运一串合法序列（内部逐张校验）。
- 交互需要 tty；管道/脚本场景请用 `--auto`（非 tty 会诚实拒绝并 exit 2）。

## 已知局限

- 无存档/读档，退出即清零；无计分、无计时。
- 不支持 draw-3、 Vegas 计分等变体。
- 行输入模式，每步需回车；不支持鼠标拖牌。
